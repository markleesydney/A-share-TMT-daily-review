# TMT 每日复盘（电子 / 通信 / 计算机 / 传媒）

申万一级行业每日量化复盘，数据源 Wind 金融数据库，配合公开财经媒体新闻归因。

## 内容

- **涨跌幅榜**：电子前 20，通信 / 计算机 / 传媒各前 10（涨、跌双榜）
- **申万二级行业排名**：按成交额加权涨跌幅排序
- **新闻归因**：每条动态与个股驱动因素均带原始新闻超链接
- **指数与 ETF 成交量**：含 5 日 / 20 日均量与量比
- **交易拥挤度**：行业成交额占比及其 60 日分位；龙头股自由流通换手率

## 拥挤度口径

行业层面用「行业成交额 / 全市场成交额」的 60 日分位数：

| 分位 | 状态 |
| --- | --- |
| ≥ 90% | 极度拥挤 |
| 70% – 90% | 偏拥挤 |
| 40% – 70% | 中性 |
| < 40% | 不拥挤 |

个股层面用自由流通换手率：≥ 15% 过热，8% – 15% 偏热。

## 颜色约定

遵循 A 股惯例：**上涨为红，下跌为绿**。

## 部署

纯静态站点，`index.html` 为入口，无构建步骤。Cloudflare Pages 配置：

- Build command：留空
- Build output directory：`/`（若仓库根即站点目录）
